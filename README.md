# Ayush | Professional Portfolio & Weather AI

A premium React portfolio featuring cutting-edge AI integrations, real-time weather predictions, and interactive speech learning tools.

## 🌟 Key Features

- **Weather Prediction Engine**: Real-time inference using Scikit-Learn models hosted on Render.
- **SpeakBetter AI**: Interactive English coaching with voice feedback.
- **Premium UI**: Glassmorphism design system built with Framer Motion, Tailwind CSS, and Shadcn UI.
- **Production Ready**: Fully configured for Netlify deployment with intelligent API routing.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS, Lucide React
- **Animations**: Framer Motion
- **State Management**: TanStack Query (React Query)
- **Backend**: FastAPI (Python), Render (Hosting)

## 🚀 Getting Started

```sh
# 1. Clone the repository
git clone <repository-url>

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
